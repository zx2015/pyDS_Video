## 1. 项目目标
开发一个跨平台 Python 桌面客户端，连接群晖 DSM 7.2，实现浏览与播放共享文件夹中的视频文件。

> **变更记录（2026-08-29）**：原计划基于 Video Station 套件（`SYNO.VideoStation.*`）。经真实设备实测，
> 该 NAS 未安装 Video Station（DSM 7.2 已从 Package Center 下架该套件），已改为直接基于
> **File Station**（`SYNO.FileStation.*`，DSM 内置、始终可用）实现浏览与流式播放，功能范围不变。

## 2. 功能范围
- **登录认证**：使用 DSM 用户名 + 密码登录，仅需支持单个 DSM 账号，无需支持两步验证（2FA）。
- **目录/文件浏览**：简单的目录树形导航（树状结构）+ 文件列表展示，根节点为 DSM 的共享文件夹（如 `/video`），不要求按影片/剧集/元数据分类，不要求海报墙等高级展示。
- **视频播放**：直接播放 File Station 提供的流式下载 URL（`SYNO.FileStation.Download`，支持 HTTP Range，可随意拖动进度条），不支持/不需要下载到本地后播放。
- **格式支持**：VLC 本身支持绝大多数常见视频格式/编码，播放能力不依赖 DSM 转码；只要 VLC 能解码，就能播放。
- **凭证管理**：账号密码加密保存在本地配置文件中（不依赖操作系统钥匙串，如 macOS Keychain / Linux Secret Service）。

## 3. 非功能需求
- **网络环境**：仅需支持局域网内访问 DSM，无需支持公网/QuickConnect 远程访问。
- **支持平台**：macOS 与 Linux（**不需要**支持 Windows）。
- **GUI 框架**：PyQt6。
- **播放后端**：优先使用 `python-vlc`（基于 VLC）作为视频播放引擎。
- **打包分发**：暂不需要打包为独立可执行文件（如 PyInstaller），能在 Python 环境中直接运行即可。

## 4. 测试要求
- 单元测试：覆盖 API 客户端、业务逻辑，网络请求需 mock。
- 集成测试：需要针对真实或模拟的 DSM 环境进行联调测试（不仅限于纯 mock 的单元测试）。
- UI 自动化测试（如 pytest-qt）：本轮未明确要求，暂不纳入范围，如后续需要可在设计阶段或迭代中补充。

## 5. 明确的非目标（Out of Scope）
- 不支持 Windows 平台。
- 不支持两步验证（2FA）登录。
- 不支持多 DSM 服务器地址的保存与切换。
- 不支持下载视频到本地离线播放。
- 不需要打包为独立可执行程序。
- 不需要海报墙、收藏、播放历史、搜索等高级功能（除非后续用户补充需求）。
